# 接口与契约

> 加载时机：新增/修改对外接口、错误码、返回结构、分页或涉及契约兼容性的改动前读取。

## 1. 门面职责

- 只做路由、参数接收、校验与转发；零业务逻辑、零事务、不直接触达数据访问层。
- 权限校验、操作日志、链路标识等横切标记在门面声明，实现下沉到基础能力。

## 2. 统一返回结构

成功与失败同构，至少包含：

| 字段 | 要求 |
|---|---|
| 结果码 | 成功/失败均可机读判定 |
| 消息 | 面向使用者可读、可定位，不暴露堆栈与内部实现 |
| 数据 | 失败时可为空，结构保持稳定 |
| 时间戳 | 统一时区 |
| 链路标识 | 可用于日志与工单追溯 |

- 失败不得只返回堆栈或纯文本；调用方必须能仅凭结果码分支处理。

## 3. 错误码与业务异常

- 错误码集中定义、按业务域分段，预留段位；禁止散落定义或魔法数字。
- 业务失败使用业务异常 + 错误码，禁止裸抛通用异常表达业务失败。
- 错误文案与错误码一一对应；文案说明「发生了什么 + 用户能做什么」。

## 4. 输入校验

- 所有外部输入必须校验：必填、类型、范围、长度、枚举值。
- 校验失败统一返回，不进入业务逻辑。
- 不信任请求体中的身份、审计与状态字段，以服务端上下文为准。

## 5. 对外数据格式

- 长整型标识对外字符串化，避免前端精度丢失。
- 金额一律使用整数最小单位，禁止浮点。
- 时间对外格式项目内统一（含时区约定）；枚举对外用稳定编码而非展示名。

## 6. 分页与排序

- 分页参数标准化：页码/游标、页大小，页大小有硬上限。
- 排序字段使用白名单，禁止任意字段透传拼接。
- 深分页有代价，列表接口优先游标或区间查询。

## 7. 契约变更

- 公共契约（接口路径、字段、事件、配置项）变更前必须说明：兼容性、影响面、迁移方式、回滚方式。
- 新增字段优先可选；删除/改名/改类型属于破坏性变更，须当次确认。
- 交付时同步更新契约文档，不留口头约定。
